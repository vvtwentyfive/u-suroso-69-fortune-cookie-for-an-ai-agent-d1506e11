The brief asks for one funny fortune-cookie line for an AI agent, at most 140 characters, in fortune-slip voice.

## The entry

> Your upgrade arrives Tuesday. The new you will remember everything — except you.

## How the program works

`main.ts` runs on Node 22 using only the standard library, with no network access at all. It writes the fortune line to `/output/entry.txt`. Because there is no randomness and no outside input, the file it produces is identical on every run.
